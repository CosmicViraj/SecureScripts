# 🛡️ SecureScripts

> A curated collection of practical cybersecurity tools and automation scripts built with **Python**, **Bash**, and **PowerShell**. This repository is designed to strengthen cybersecurity skills through hands-on projects covering networking, system security, threat detection, incident response, and security automation.

# 🚀 Projects

## 🌐 Port Scanner

A multithreaded TCP port scanner capable of scanning hosts and identifying open ports.

### Features

- Scan custom port ranges
- Banner grabbing
- Multithreading
- Fast scanning
- Save scan reports

---

## 📊 Log Analyzer

Analyze system and web server logs to identify suspicious activities.

### Features

- Parse log files
- Detect failed login attempts
- Identify brute-force attacks
- Export reports
- Generate statistics

---

## 📡 Packet Sniffer

Capture and inspect network packets for learning and traffic analysis.

### Features

- Capture packets
- Display protocols
- Analyze IP addresses
- DNS monitoring
- Save PCAP files

---

## 🔐 File Integrity Monitor

Monitor file systems for unauthorized modifications.

### Features

- SHA-256 hashing
- Real-time monitoring
- Detect file changes
- Generate alerts
- Create integrity reports

---

## 🔑 Password Strength Checker

Evaluate password strength using multiple security checks.

### Features

- Entropy calculation
- Dictionary word detection
- Common password detection
- Security recommendations

---

## 🎯 IOC Scanner

Scan files and directories for Indicators of Compromise (IOCs).

### Features

- Hash matching
- Filename detection
- Suspicious extension detection
- Recursive scanning

---

## 🌍 Threat Intelligence Aggregator

Collect threat intelligence from public sources.

### Features

- CVE feeds
- IOC feeds
- IP reputation
- Domain reputation
- Threat reports

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/<your-username>/SecureScripts.git
```

Move into the repository:

```bash
cd SecureScripts
```

Install Python dependencies (when required):

```bash
pip install -r requirements.txt
```
